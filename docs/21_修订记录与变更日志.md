## 4. 维护约定

1. **先改数据、再改结论**：智算集群章节的任何数值变更，先改《附录 C 口径基线表》，再同步正文；
2. **图文同版本**：架构图、xlsx 与文档必须纳入同一版本号体系，每次修订强制复核图文一致性；
3. **每次发布必登记**：新增/修改章节后，更新本页「版本总览」与「详细修订记录」，并记录线上提交号；
4. **锚点稳定**：章节顺序调整会导致页面锚点（`doc-NN`）变化，引用外部链接时请使用章节标题而非锚点。
